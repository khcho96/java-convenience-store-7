## 기능 구현 목록
> 기능 작동 순서대로 작성

1. 파일 입력 & 재고 저장
2. 재고 출력
    - 이름, 가격, 개수(“재고 없음”), (프로모션)
3. 구매 상품 및 수량 입력 및 검증
    - 예외 사항
        - 잘못된 형식인 경우 -> Validator
            - 올바르지 않은 형식으로 입력했습니다. 다시 입력해 주세요.
        - 존재하지 않는 상품을 입력한 경우 -> Stock
            - 존재하지 않는 상품입니다. 다시 입력해 주세요.
        - 구매 수량이 재고 수량을 초과한 경우 -> Stock
            - 재고 수량을 초과하여 구매할 수 없습니다.
4. 프로모션 적용 가능 상품에 대해 고객이 해당 수량보다 적게 가져온 경우 그 수량만큼 추가 여부 입력 및 검증
    - 필요한 요소: 상품명
    - 예외 사항
        - Y, N이 아닌 경우 -> Option
            - 잘못된 입력입니다. 다시 입력해 주세요.
    1. Y: 증정 맏을 수 있는 상품 추가
    2. N: 추가하지 않는다,
5. 프로모션 재고가 부족하여 일부 수량을 프로모션 혜택 없이 결제해야 하는 경우, 일부 수량에 대해 정가로 결제할지 여부 입력 및 검증
    - 필요한 요소: 상품명, 혜택 없이 결제해야 하는 수량
    - 예외 사항
        - Y, N이 아닌 경우 -> Option
            - 잘못된 입력입니다. 다시 입력해 주세요.
    1. Y: 일부 수량에 대해 정가로 결제
    2. N: 정가 결제 수량 제외 후 결제 진행
6. 멤버십 할인 적용 여부 입력
    - 예외 사항
        - Y, N이 아닌 경우 -> Option
            - 잘못된 입력입니다. 다시 입력해 주세요.
    1. Y: 멤버십 할인 적용
        - 프로모션 미적용 금액의 30% 할인
        - 할인 최대 한도 8000원
    2. N: 멤버십 할인 적용X
7. 영수증 출력
    - 구매 상품 내역
        - 상품명, 수량, 금액
    - 증정 상품 내역
        - 상품명, 수량
    - 금액 정보
        - 총구매액 - 수량, 금액
        - 행사할인 - 금액(음수)
        - 멤버십할인 - 금액(음수)
        - 내실돈 - 금액
8. 추가 구매 여부 입력
    - 예외 사항
        - Y, N이 아닌 경우 -> Option
            - 잘못된 입력입니다. 다시 입력해 주세요.
    1. Y: 업데이트돤 재고 목록 출력 후 구매 진행
    2. 구매 종료
